                    Collection backups

                    Each time you load a collection.nml in Playlist Builder, NMLify saves a compressed snapshot here. If Traktor corrupts your collection during a playlist import, download the most recent snapshot and replace collection.nml in your Traktor folder to roll back.

                    Snapshots live in this browser only — they're never uploaded. We keep the most recent 10 and prune older ones automatically. Reloading the same file does not create a duplicate.

                        How to import a stem package
                        1. Choose the package folder you received.
                        2. Choose where to copy the originals, then enter that same folder's absolute path as Traktor sees it.
                        3. Install the originals. NMLify creates a new stem-share-ready.nml with paths for this computer.
                        4. Install the stems into Traktor's configured generated stems folder.
                        5. Import the new stem-share-ready.nml into Traktor—not the package's original stem-share.nml.
